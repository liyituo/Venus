## 目标

在 llm_server.py 的 agent 工具体系上补齐编程助手工作闭环：检索、精确编辑（带 diff 确认）、Git、长进程、任务规划、代码索引。前端（chat.py / cli.py）同步支持 diff 确认框和 todo 面板。

## 新增 16 个工具（总数 11 → 27）

**检索（3）** — 全部只读，auto 模式免确认，进 QUERY_TOOLS：
- `search_text(pattern, path, file_pattern, max_results, context_lines)` — 正则搜索工作区，返回 `文件:行号:内容` + 上下文；跳过 .venv/.git/__pycache__/node_modules、二进制、>1MB 文件
- `glob_files(pattern)` — 文件名模式匹配，返回相对路径 + 大小 + 行数
- `list_symbols(file)` — 单文件符号表（def/class/async def + 行号 + 签名）

**编辑（1）** — 敏感操作，恒确认：
- `replace_text(file, old, new, occurrence)` — 精确替换；用 difflib 生成 unified diff；**ask 事件 payload 新增 `diff` 字段**，用户看完 diff 再允许/拒绝；replace_text 加入 CONFIRM_TOOLS（_needs_confirm 恒 True）

**Git（4）** — 只读 3 个免确认，`git_commit` 恒确认：
- `git_status(path)` / `git_diff(path, staged, stat)` / `git_log(n)` — 均为只读查询
- `git_commit(message, path)` — 内部 git add -A + commit，确认时 diff 字段带 `git diff --stat` 摘要
- 安全：git 仓库根必须在 workspace 内（`_find_git_root` 向上找 .git，root 越出 workspace 则拒绝）；命令走 subprocess 数组形式（无 shell 注入）

**进程（4）** — `start_process` 非只读命令确认；只读查询免确认：
- `start_process(command, cwd)` — Popen 后台启动，命令过 DANGEROUS_PATTERNS 黑名单；POSIX 用 start_new_session + killpg 杀整组，Windows 用 CREATE_NEW_PROCESS_GROUP + taskkill /T；上限 8 个并发
- `process_output(pid, tail, wait_seconds)` — 返回缓冲输出尾部 + 运行状态；后台线程逐行读入 deque(maxlen=2000)
- `stop_process(pid)` / `list_processes()`

**任务规划（3）**：
- `create_todo(title, description)` / `update_todo(id, status)` / `list_todos()` — 全局一份（_agent_lock 已保证单任务互斥）；每次变更发新 SSE 事件 `todo_update`（payload: `{todos: [...]}`）；**持久化到 `workspace/.pcagent/todos.json`**，每次 agent 请求把 todo 注入 system 消息 → 中断后新对话模型能看到进度，实现「半恢复」（完整任务重放不做）

**索引（1）**：
- `repo_map(path, depth, max_entries)` — 扫描 workspace 生成目录树 + 文件行数 + 顶层符号（每文件最多 20 个）；30 秒 TTL 缓存；跳过隐藏目录/.venv/.git 等

- create_file 覆盖时的 diff 展示（保持现有确认，只给 replace_text 加 diff）
